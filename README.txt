WOD Lab - offline app

Option 1 - quickest (computer): open WOD-Lab.html in Chrome, Edge or Safari. Everything works offline.
Your log is stored in that browser on that computer.

Option 2 - installable app with its own icon (phone or computer): this folder must be served once over https.
 1. Put this folder online for free, e.g. drag it onto https://app.netlify.com/drop (keep the site by signing up),
    or push it to a GitHub repository and turn on GitHub Pages.
 2. Open the link on your phone.
    iPhone (Safari): Share > Add to Home Screen.   Android (Chrome): menu > Install app / Add to Home screen.
    Computer (Chrome/Edge): the install icon in the address bar.
 3. After the first visit it runs fully offline from its icon.

Your log stays on the device. Use Log > Backup > Export log to keep a copy or move it to another device,
and Import log on the other side.
